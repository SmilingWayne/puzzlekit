# PuzzleKit

PuzzleKit v0.4.0 is a Python interface to the Rust cspuz URL solver. It is
currently in development and has a different API from earlier releases.

See the [project README](https://github.com/SmilingWayne/puzzlekit#readme) for
installation, usage, supported adapters, and the source layout. The
[integration notes](CSPUZ_INTEGRATION.md) describe the native bridge and result
semantics. The [shading](V040_SHADING_ADAPTERS.md) and
[extended](V040_EXTENDED_ADAPTERS.md) adapter reports record their verification
scope and limitations.

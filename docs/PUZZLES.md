## Regenerating

```sh
# Refresh the snapshot from the sibling pzprjs and puzzlekit-dataset checkouts
python scripts/puzzle_table.py collect
# Rebuild this page and the README summary from the snapshot
python scripts/puzzle_table.py render --write
# Verify they are current (also run in CI)
python scripts/puzzle_table.py render --check
```

`s?` is computed from the adapter registry every time `render` runs, so
adding an adapter only needs `render --write`. The dataset columns come from
the committed snapshot, `docs/puzzle_table.json`. To add a column, register a
collector or a derived field and a `Column` in `scripts/puzzle_table.py`.
